# @harf/core

Framework-agnostic RTL and Arabic logic. **Zero runtime dependencies** — this is enforced, not aspirational.

Direction resolution, the logical style transform, bidi isolation, numeral systems, Hijri dates and deterministic currency formatting all live here. Adapters are thin wrappers over this package.

> **Status: pre-alpha.** Not yet published to npm. See the [root README](../../README.md) for what is and is not built.

## Install

```bash
pnpm add @harf/core
```

# @harf/react

React (web) adapter for Harf: `DirectionProvider`, `useDirection`, `useLogicalStyles` and `<Bidi>`.

On the web, most logical layout is already handled by CSS logical properties. This package exists for what CSS does not give you: a direction value React can react to, and correct bidirectional isolation of embedded LTR runs.

> **Status: pre-alpha.** Not yet published to npm. See the [root README](../../README.md) for what is and is not built.

## Install

```bash
pnpm add @harf/react
```
